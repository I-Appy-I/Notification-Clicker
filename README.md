# Notification-Clicker

i have used the Notification API , first we check if the browser supports the notification API using ("Notification" in window) , if yes then we enable the button to enable notification (both buttons are initially disabled) to make the user able to enable the notification permission for our site.

after user grants permission to send notification , we enable the "send notification" button , when user clicks on it , we create a new notification saying hello.
